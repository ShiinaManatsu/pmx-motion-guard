# PMX Retarget Guard

Blender 5.3 / Windows x64 的 PMX 动画穿插修正插件。

## 使用

通过 Blender 偏好设置中的从磁盘安装选择 release 目录中的 ZIP。3D 视图 N 面板打开 PMX Guard，选择 PMX 主网格，点击分析模型。检查骨骼映射和身体材质，再选择当前帧或动画范围处理。

偏好设置提供持久缓存路径、DeepSeek 地址、模型和密码显示的 API key。默认缓存位于 Blender DATAFILES/pmx_retarget_guard。映射同时保存在网格对象属性与磁盘指纹缓存。标准 PMX 使用本地识别，DeepSeek 可补充缺失映射。

修正结果包含可播放 PC2 网格缓存与独立烘焙骨架。烘焙骨架保留原始全部骨名和骨骼，用于挂接饰品，动作放在自身 NLA Replace 片段中。导出 Alembic 保存最终网格形变，FBX 保存配套骨架动画。时间轴帧数沿用 Blender 工程。

结果对象的切换按钮控制原始与修正对象的视口显示。渲染或导出前选择所需对象及可见性。缓存路径随工程保存，移动工程时需携带缓存目录或已导出的 Alembic。

## 当前求解行为

0.1 使用逐帧求值网格构建姿态局部求解包，沿用已验证的 PMX 静态试验路径。骨骼修正量提供时间滤波。此版本的骨骼输出在独立烘焙骨架上生成。过滤关闭的关节在原生 QP 中锁定为零修正，完整身体继续参与检测。

骨骼模式仍使用代理权重生成显示网格。烘焙骨架通过同一代理区域变换原骨姿态，为附件提供运动位置。原 PMX 蒙皮与辅助骨的精确回写、固定静止角色包的原生连续求解和 IK 控制器修正仍需要进一步实现与验证。

Alembic 记录每帧最终网格，FBX 包含全部烘焙骨骼。FBX 重导入测试使用 anim_offset=0，Blender FBX 导入器默认偏移为 1 帧。

取消操作在当前帧计算结束后生效。长动作的逐帧包和网格缓存会占用磁盘空间。已有结果保留为独立对象，便于比较多组参数。
